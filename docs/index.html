Under the Hood

            
Why It Feels Like CS: Source

          

        

        

          

            
Authentic AirAccelerate

            

              Projection along your wish vector is clamped to sv_air_max_wishspeed (30 u/s),
              while acceleration scales by your full 250 u/s wishspeed — rewarding smooth mouse curves perpendicular to velocity.
            

            
add = min(wish, 30) - dot(vel, dir)
gain = min(add, aa * wish * dt)

          

          

            
ClipVelocity Surf Planes

            

              On custom 30° / 45° / 60° surf ramps or vanilla stairs/snow/slabs, inward velocity projects cleanly onto the ramp plane with zero ledge snags.
            

            
backoff = dot(vel, normal) * overbounce
vel -= normal * backoff

          

          

            
Bhop Friction Skip & Stamina

            

              Hitting a jump on the landing frame (via Space, scroll wheel, or sv_jump_buffer_ticks) fires before Friction(), preserving 100% momentum unless Valve's 1.1x cap is active.
            

            
if (onGround && wantsJump) jump(); // skips friction

          

          

            
Air Crouch-Jump (+18 HU)

            

              Mid-air crouching shrinks the collision hull to CS:S 54 HU (1.35m) with 46 HU (1.15m) eye height and lifts feet upward +0.45 blocks when overhead is clear.
            

            
stand: 0.6 x 1.80m · crouch: 0.6 x 1.35m

          

          

            
Fast Ladder Strafing

            

              Combining W with A/D on ladders projects both inputs onto the ladder face tangent for diagonal √2 climb speed and push-off jumps.
            

            
climb = normalDot * look + tang * side

          

          

            
Edgebug & Jumpbug Tech

            

              Skimming a solid block corner at high downward velocity triggers an Edgebug fall-save; timing an uncrouch-jump right before impact triggers a Jumpbug with HUD + chime feedback.
            

            
edgebug: !centerBelow && edgeHit && vy < -340

Setup

            
Installation (Minecraft 26.3 + Fabric)

          

        

        

          

            
Client & Server

            
    
              
  1. Install Fabric Loader >=0.19.5 for Minecraft 26.3 (Java 25).
    2. 
              
  2. Add Fabric API 0.166.2+26.3 (and optional Mod Menu 21.0.1) to your mods/ folder.
    3. 
              
  3. Drop sourcecraft-1.0.0.jar into both client and server mods/ folders for full multiplayer sync, or singleplayer client only.
    4. 
            

          

          

            
Build From Source

            
git clone https://github.com/hazeg7/Source-Craft.git
cd Source-Craft
./gradlew clean test build
# Output: build/libs/sourcecraft-1.0.0.jar
